# Publication Scope

This repository prepares a presentation package for initial grant and technical review. It remains private during preparation; any public release is a separate later step.

## Included

- Project purpose and intended public benefit.
- A high-level description of the existing prototype.
- Established cryptographic construction names and their conceptual roles.
- Clear limits of decentralization, privacy and security assurance.
- Proposed research questions, evaluation measures and an indicative schedule.
- General resource needs and illustrative planning allocations.
- Translations of the core reviewer brief.
- Reviewed presentation media, when available.
- Video scripts and storyboards, clearly distinguished from generated media and speech transcripts.
- Dated, aggregated engineering statistics and high-level regression examples, with unresolved issues stated explicitly.

## Outside this repository

Implementation code, private design specifications, packet formats, deployment instructions, live addresses, infrastructure configuration, credentials, private keys, recovery material, account identifiers, private correspondence and application records are not part of this package.

Personal contact details and financial account information are not needed here. The public repository-owner profile provides attribution; correspondence can continue through the channel in which this material was shared.

## Interpretation

Public access to these documents does not grant access to private systems or an implementation licence. This repository distributes documentation, not an implementation.

Descriptions of the current prototype are separated from proposed work. A completed integration, independent audit, funding award or partner endorsement must not be inferred without explicit supporting evidence.

The English edition is the reference text. Translation differences should be resolved against that edition.

Any future addition to this repository should be reviewed against this publication boundary before it is committed.
