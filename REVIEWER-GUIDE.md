# Reviewer Guide

This repository supports an initial assessment of Alice Talk's goals, current prototype, research questions and resource needs.

## Suggested reading

1. Read the [main overview](README.md).
2. Choose one of the seven language editions linked there.
3. Pay particular attention to the distinction between current prototype behavior and proposed cross-device or agent features.
4. Review the stated privacy boundaries, independent-review gap and proposed evaluation measures.
5. Consider whether a small, bounded contribution fits the research plan.

The English [project brief](docs/en/overview.md) is the reference edition. Each translation covers the same core reviewer material.

## Questions worth asking

- Is the proposed experiment sufficiently bounded to produce useful evidence?
- Are authenticated identity and action permission treated as separate controls?
- Are current limitations described clearly enough for the proposed stage?
- Can the work be resized to the available resources?
- What would count as a useful result, including a negative result?
- What further evidence would be needed before a production or security claim?

## Review scope

The current implementation is experimental and independently unaudited. This public material is not sufficient for a cryptographic audit or production acceptance.

No existing award, sponsor endorsement, model-provider approval or completed third-party integration should be inferred from the proposal.

For enquiries, use the correspondence through which this repository was shared. No private information needs to be posted publicly for an initial review.
